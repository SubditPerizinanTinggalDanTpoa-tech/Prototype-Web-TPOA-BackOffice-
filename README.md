# Prototype Portal Kemitraan Organisasi Asing

Prototype ini saya rancang dan kembangkan sebagai bahan awal untuk membahas pengelolaan data dan proses layanan bagi organisasi asing (INGO). Saya menangani pengembangan utama pada sisi frontend. Dalam prosesnya, Nabila dan Immanuel turut membantu riset, dengan dukungan dari Subdit TPOA dan Subdit Perizinan Tinggal.

## Tujuan

Versi pertama ini disiapkan sebagai bahan presentasi dan diskusi awal. Catatan serta arahan dari para pihak yang meninjau akan menjadi masukan untuk menyempurnakan rancangan sebelum pengembangan tahap berikutnya.

## Tentang Prototype

Prototype ini menggambarkan rancangan awal portal, termasuk pengelolaan data INGO, pendaftaran, perizinan operasional, pemantauan, dan data personel. Fokus versi saat ini adalah penyajian alur dan kebutuhan awal, bukan menggantikan proses atau sistem resmi.

- **Status:** Prototype tahap pertama
- **Data:** Data dummy untuk kebutuhan demonstrasi
- **Demo:** [Buka prototype](https://subditperizinantinggaldantpoa-tech.github.io/Prototype-Web-TPOA-BackOffice-/)

> **Catatan:** Situs ini belum merupakan layanan resmi, belum terhubung ke sistem internal, dan tidak untuk digunakan dalam proses operasional. Jangan memasukkan data pribadi atau data kedinasan yang sebenarnya.

## Tim dan Dukungan

Pengembangan utama dikerjakan oleh Ramandha Akbar. Terima kasih kepada Nabila dan Immanuel atas bantuan riset, serta rekan-rekan di Subdit TPOA dan Subdit Perizinan Tinggal atas dukungan dan ruang diskusi selama penyusunan prototype ini.

Prototype tahap pertama ini akan dipresentasikan kepada Bapak Direktur Konsuler dan menjadi bahan pembahasan bersama Bapak Arief selaku Kasubdit, Sekretaris TPOA, serta Bapak Tolhah selaku Ketua TPOA.

## Teknologi

- **Frontend:** React 19, TypeScript, dan Tailwind CSS v4
- **Build dan development:** Vite
- **Backend:** Belum tersedia pada tahap prototype ini
- **Penyimpanan demo:** Data contoh dan perubahan disimpan di `localStorage` pada browser yang digunakan; belum ada database atau API bersama
- **Email:** Alur status email hanya simulasi dan tidak mengirim email sungguhan
